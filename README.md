# Learn100

用自己的话，把 AI 概念讲出来。

Learn100 是一个通过语音对话练习 AI 概念的学习工具。每次聚焦一个概念：先听一段讲解，再用自己的话复述，并回答一次追问。通话结束后，系统根据转写给出要点反馈。学习记录保存在当前浏览器，可导出为 JSON。

> **项目状态：实验版。** 仓库包含 100 个 AI 基础概念。在线体验页尚未发布，评分逻辑仍在验证，结果仅供参考。

## 使用前准备

需要两把 API Key，都在你自己的账号下申请：

- **豆包语音**：实时语音通话使用，即豆包语音控制台的 `X-Api-Key`；
- **火山方舟**：通话结束后的文本评分使用。

## Key 与数据的去向

- Key 保存在当前浏览器的 `localStorage`，不写入仓库，也不存到服务端。
- 通话和评分时，浏览器通过本项目的中转 Worker 把请求转发给豆包或方舟，因为浏览器无法直接设置豆包要求的请求头。
- Worker 只在请求过程中使用 Key，代码中不写日志、不做持久化。托管平台自身的请求日志不在本仓库的控制范围内。
- 转写和评分结果保存在浏览器的 IndexedDB 中，可导出为 JSON。

## 本地运行

需要 Node.js 22（当前开发环境使用的版本）。

```bash
npm install
npm run dev     # 本地预览界面，不包含语音中转
npm test        # 离线评分测试；设置 ARK_API_KEY 后还会运行真实模型样例
npm run check   # 语法检查
npm run build   # 生成 dist/，其中是可部署为 Cloudflare Worker 的 ESM 包
```

`npm run dev` 只能预览界面，要完成语音通话需要部署中转 Worker 并提供有效的 Key。

## 项目结构

- `data/`：概念内容，6 个 JSON 与总清单 CSV。教学顺序为入门 20 加批次 1–5。
- `public/`：浏览器界面、讲师与判官提示词、评分约束、音频、本地存储。
- `worker/`：语音 WebSocket 中转与方舟评分中转。
- `scripts/`：构建与本地预览脚本。
- `tests/`：离线合约测试，以及可选的真实模型样例测试。
- `docs/`：豆包实时语音接入的调研记录，以及[设计说明](docs/设计说明.md)。

## 内容说明

概念内容在 `data/` 中。易变概念（如产品、模型、政策相关内容）只讲通用思路，不引用具体产品和价格。每个概念的来源编号在 `sources` 字段中，易变概念的联网核对记录在 `web_checks` 中。
